어떤 쇼츠를 만들까요?

주제만 적으면 대본·목소리·편집까지 자동으로 만들어요.

주제 칸에 키워드를 쓰면 그 키워드로, 비워두면 오늘의 인기 주제로 추천해요.
🎬 영상 요청 메모 (선택) — 어떤 영상·사진으로 만들지
적은 내용은 대본 구성, 장면 고르기, 사진 검색에 반영돼요. 단, 확인 안 된 사실이나 저작권 있는 자료는 메모에 있어도 쓰지 않아요.
자료 조사 + 사실 검증검색으로 실제 자료를 모으고, 근거가 확인된 사실만 써요. 핵심 사실이 확인 안 되면 영상을 만들지 않아요
📎 참고 글로 만들기 (블로그·기사 링크 또는 글 붙여넣기)
첨부한 글에 있는 사실만 써서, 문장은 새로 써요. 출처는 설명란에 들어가요.
🎨 내 이미지로 만들기 (구독 중인 앱 활용, 추가 비용 0원)
① 만들기를 누르면 대본과 장면별 이미지 문구가 '대본 확인 대기'에 와요
② 확인·수정을 열고 장면마다 문구 복사 → 제미나이·ChatGPT 앱에 붙여넣어 이미지 만들기 → 사진첩에 저장
③ 같은 화면에서 ＋ 이미지 올리기로 올리고, 장면마다 쓸 이미지 고르기
④ 이 대본으로 영상 만들기 → 이미지 + 목소리 + 자막으로 완성 (이미지 없는 장면은 무료 영상으로 채워요)
실화·사건·우주·연구 주제에 좋아요. 한국 공공 자료(정책브리핑·국가기록원·e영상역사관 등 공공누리 제1유형)와 위키미디어 커먼즈·NASA의 자유 이용 실제 사진·기록 영상을 찾아 쓰고, 출처는 설명란에 자동으로 적어요.
링크로 가져오기
유튜브, 인스타그램, 구글 드라이브, 비메오, 인터넷 아카이브, 위키미디어 커먼즈 링크를 붙여넣으세요.
링크 사용 안내 (드라이브·유튜브 CC 찾기)
  1. 구글 드라이브 앱 → ＋ → 업로드 → 영상 선택
  2. 올라간 영상의 ⋮ → 공유 → 액세스 관리
  3. 일반 액세스를 링크가 있는 모든 사용자로 변경
  4. 링크 복사 → 여기에 붙여넣기
유튜브 CC 영상 찾는 법: 유튜브에서 검색 → 필터 → 기능에서 크리에이티브 커먼즈 선택
내 영상 보관함
쓸 영상을 순서대로 눌러 고르세요. 주제를 비워두면 AI가 영상을 보고 정해요.

무료 영상·사진과 골고루 섞어요. 제미나이 이미지는 유료일 수 있어요(1장 약 40~60원). 결제가 안 돼 있으면 자동으로 사진·영상만 써요.
