롱폼 영상 링크
구글 드라이브, 비메오, 인터넷 아카이브, 위키미디어 커먼즈 링크를 붙여넣으세요.
구글 드라이브 링크 만드는 법
  1. 구글 드라이브 앱 → ＋ → 업로드 → 영상 선택
  2. 올라간 영상의 ⋮ → 공유 → 액세스 관리
  3. 일반 액세스를 링크가 있는 모든 사용자로 변경
  4. 링크 복사 → 여기에 붙여넣기
유튜브 링크는 유튜브가 자동으로 가져오는 걸 막아요. 영상을 받아서 드라이브나 '내 영상'으로 올려주세요.

유튜브에 올리는 방법 펼치기
  1. 영상 받기 → 휴대폰이면 공유 → 비디오 저장
  2. 유튜브 앱에서 1분 몸상식 채널인지 확인
  3. ＋ → 동영상 업로드 → 영상 선택
  4. 여기서 제목·설명 복사 → 붙여넣기
  5. 공개 상태 비공개 → 확인 후 공개로 변경
  6. 업로드 후 고정 댓글 복사해서 댓글 고정
